08 — IDOR: Corrigido Mesma URL → HTTP 404 Not Found
← Anterior ↑ Topo
☰ TaskHub
Olá, bob + Nova Tarefa Sair
🔗 URL http://localhost:5000/tasks/edit/1 ✅ Acesso bloqueado
✅
CORREÇÃO APLICADA — A query agora inclui a verificação de dono:
Task.query.filter_by(id=task_id, user_id=current_user.id).first_or_404()
Bob tentou acessar /tasks/edit/1 (tarefa de Alice) e recebeu 404 Not Found.
404
Not Found
Tarefa não encontrada ou sem permissão de acesso.
Você não pode visualizar ou editar tarefas de outros usuários.
← Voltar à lista
✗ Código vulnerável → ✓ Código corrigido 
# Antes (vulnerável) — busca apenas pelo ID
- task = Task.query.get_or_404(task_id)

# Depois (corrigido) — exige que a tarefa pertença ao usuário
+ task = Task.query.filter_by(
+     id=task_id,
+     user_id=current_user.id
+ ).first_or_404()

# Resultado: Bob acessa /tasks/edit/1 → HTTP 404
# A tarefa de Alice não é retornada para outros usuários
